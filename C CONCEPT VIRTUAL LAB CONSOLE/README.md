# 🧪 C Concept Virtual Lab Console

> An interactive, menu-driven virtual lab built in **C** to help beginners understand and practice core programming concepts through hands-on examples and guided explanations.

---

## 📌 Overview

The **C Concept Virtual Lab Console** is an educational, console-based application designed to make learning C programming more interactive and approachable.

Instead of simply reading theory, users can explore concepts through structured modules, practical demonstrations, and beginner-friendly explanations—all within a menu-driven interface.

The project covers essential programming topics such as arrays, strings, pointers, functions, pattern printing, and utility programs, making it suitable for students, beginners, and interview preparation.

---

# ✨ Features

### 📖 Basic Concepts Explorer

Learn the fundamentals of C programming, including:

- Data types
- Variables
- Operators
- Input and Output
- Loops
- Conditional statements

---

### 📚 Arrays & Strings Lab

Explore common array and string operations through practical examples.

Features include:

- One-dimensional arrays
- Two-dimensional arrays
- Character arrays
- String library functions
  - `strlen()`
  - `strcmp()`
  - `strcpy()`
  - `strcat()`
- Safe string input using `fgets()`

---

### 🎯 Pointer Playground

Understand memory and pointers with interactive demonstrations.

Topics covered:

- Pointer declaration
- Pointer dereferencing
- Pointer arithmetic
- Double pointers
- Address tracing using `&`, `*`, and `**`

---

### ⚙ Functions & Modular Programming

Learn how functions improve code organization.

Includes demonstrations of:

- Function prototypes
- Function calls
- Call-by-value
- Global variables
- Local variables
- Modular program structure

---

### ⭐ Pattern Printing Lab

Practice nested loops by generating different patterns.

Includes:

- Star patterns
- Number patterns
- Geometric shapes
- Step-by-step explanation of inner and outer loops

---

### 🧰 Utility Programs

Additional mini-programs include:

- Minimum/Maximum finder
- Temperature converter
- Basic calculator
- Data type storage viewer using `sizeof()`

---

### 💻 User-Friendly Interface

Designed with beginners in mind.

Features:

- Menu-driven navigation
- Input validation
- Continuous interaction using `while(1)`
- Clean exit using `exit(0)`

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/200N7/PROJECTS.git
```

---

## 2. Navigate to the Project Folder

```bash
cd PROJECTS/C_Concept_Virtual_Lab_Console
```

---

## 3. Compile the Program

```bash
gcc main.c -o lab
```

> If your project uses multiple source files:

```bash
gcc main.c modules.c -o lab
```

---

## 4. Run the Program

### Linux / macOS

```bash
./lab
```

### Windows

```bash
lab.exe
```
