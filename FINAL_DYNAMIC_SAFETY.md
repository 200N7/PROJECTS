# Final Dynamic Verification Safety

The adaptive planner follows a strict evidence invariant: endpoint reachability is not business correctness. If an independent deterministic oracle cannot be synthesized, the criterion remains INCONCLUSIVE rather than being promoted from HTTP 200 alone.

The planner now gathers literal project data across Python modules, grounds categorical and boolean filters, supports numeric threshold predicates, binds multiple JSON assertions independently, and uses response schema only to select fields—not expected values. Composite formulas that cannot yet be independently synthesized are deliberately left INCONCLUSIVE.
